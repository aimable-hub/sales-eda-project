# Sales Exploratory Data Analysis (EDA) Project

## Project Objective
The objective of this project was to perform exploratory data analysis on a sales dataset to identify patterns, trends, distributions, and business insights related to products, referral sources, payment methods, and revenue performance.

## Dataset Description
The dataset contains transactional sales data including:
- Products
- Revenue
- Referral sources
- Payment methods
- Coupon usage
- Customer transactions
- Order statuses

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Descriptive Statistics
- GitHub

## Analysis Performed
- Mean, median, and count calculations
- Revenue trend analysis
- Product performance analysis
- Referral source analysis
- Payment method distribution
- Order status distribution
- Outlier identification

## Key Findings
- Instagram generated the highest referral revenue
- Credit Card and Online payments dominated transactions
- Several high-value transactions were identified as outliers
- Revenue was distributed relatively evenly across product categories
